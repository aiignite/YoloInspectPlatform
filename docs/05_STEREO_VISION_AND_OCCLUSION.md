# 方案 05：双目立体视觉多视角几何融合与物理盲区消除方案

## 1. 方案背景与单目盲区痛点

在精密的微电子装配与锁螺丝工位，单目 2D/2.5D 相机存在无法克服的**物理自遮挡（Self-Occlusion）与深度尺度模糊**：
1. **手背反转遮挡（Dorsal Occlusion）**：当操作员手背朝向镜头向下抓取深腔工装内的零件时，手背完全遮挡了拇指与食指的抓夹接触面，单目算法无法确认器件是否真正被捏取或已脱落；
2. **工具遮挡（Tool Occlusion）**：手持电批或胶枪作业时，粗大的工具外壳遮挡了螺丝孔位与指尖前端；
3. **单目 Z 轴空间漂移**：单目通过手掌相对大小估算深度时，操作员手掌大小差异（骨骼比例）会导致 Z 轴测距误差高达 $\pm 8\text{mm}$，无法精确判别器件是否已压接到位。

**优化目标**：构建“**主视角俯视 + 侧视 45° 辅助视角**”的双目立体几何融合系统，彻底消除遮挡盲区，实现三维空间 $\le \pm 0.8\text{mm}$ 的高精坐标解算。

## 2. 空间布局与立体融合算法管线

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      双目立体视角布置与空间对齐拓扑                     │
 │                                                                        │
 │         [相机 A: 顶视 90°]                 [相机 B: 侧视 45°]          │
 │         (主控: X/Y 平面轨迹)               (主控: Z 轴深度与下压行程)  │
 │                 │                                   │                  │
 │                 ▼                                   ▼                  │
 │           [图像 A (21点)]                     [图像 B (21点)]          │
 │                 │                                   │                  │
 │                 └───────────────┬───────────────────┘                  │
 │                                 │                                      │
 │                                 ▼                                      │
 │            [双目立体标定矩阵 (张正友标定法: R, T, K1, K2)]             │
 │                                 │                                      │
 │                                 ▼                                      │
 │        [置信度加权光线投射三角测量 (Confidence-Weighted Triangulation)] │
 │          • 若相机 A 某关节被遮挡 (Conf_A < 0.3)，则权重 100% 倾斜给相机 B│
 │          • 重构出 3D 绝对物理空间坐标: P_world(X, Y, Z) in mm          │
 │                                 │                                      │
 │                                 ▼                                      │
 │               [3D 黄金标准空间包络线判定 (Spatial Envelope)]            │
 └────────────────────────────────────────────────────────────────────────┘
```

### 空间几何重建数学模型
对于空间中同一个关节点 $P = [X, Y, Z]^T$，在两台相机归一化平面的投影坐标分别为 $x_1, x_2$，满足对极几何约束：
$$x_2^T F x_1 = 0 \quad (\text{其中 } F \text{ 为基础矩阵})$$
通过奇异值分解（SVD）对直接线性变换（DLT）进行求解：
$$A \cdot P = 0 \implies \min \|A P\| \quad \text{s.t. } \|P\| = 1$$
解算得到绝对毫米级三维坐标，实现对工具和手背遮挡的 100% 互补重构。
