# 工业视觉与SOP动作合规监控系统：生产环境落地优化总览与并行实施路线图

## 1. 方案背景与系统演进总览

本系统已经在手部 21 关节点三维拓扑解析、YOLO 目标识别、动态平滑滤波（EMA）、黄金标准动作库录制、DTW 动态时序规整比对、SOP 合规防呆（Poka-Yoke）以及 Recharts 实时置信度趋势监测等软件业务层实现了完整闭环。

为了将系统从“验证演示环境”成功交付至**7×24 小时高负荷运转的工业现场**（如 3C SMT 电子装配、汽车电子精密插装、半导体封装测试），必须解决工业环境下的**超低延迟确定性、光照及反光抗干扰、PLC 物理硬联锁、多视角盲区消除、离线自治容灾与隐私合规**等核心工程问题。

## 3. 并行实施可行性分析（Parallel Feasibility Analysis）

为了最大化缩短项目落地周期，六大方案被划分为 **三条高度可并行的专业工程轨道（Tracks）**：

1. **轨道 A：算法与推理性能工程（软件/AI组）**
   * 包括：`[方案 03] 模型量化与 TensorRT` + `[方案 01] 边端微服务接口定义`
   * 可行性：**100% 独立并行**。算法工程师可在开发服务器或独立工控机上，使用已有开源数据集与现场实录样本直接进行模型导出、量化调优及基准测试，无需等待现场物理相机安装。

2. **轨道 B：现场物理硬件与光学系统（自动化/电气组）**
   * 包括：`[方案 02] 工业相机与光学打光` + `[方案 04] PLC现场总线与物理联锁`
   * 可行性：**100% 独立并行**。电气与机械工程师可在样板工位进行相机支架打样、光源角度调试、PLC 逻辑点位分配与接线，形成独立的硬触发与总线控制底座。

3. **轨道 C：应用集成、几何融合与系统合规（全栈/系统组）**
   * 包括：`[方案 05] 双目多视角融合` + `[方案 06] 边缘离线自治与隐私脱敏`
   * 可行性：前期独立开发离线存储缓冲与脱敏算子；待轨道 A（模型引擎）与轨道 B（双相机挂载）就绪后，在第二周周末进行外参联合标定与全链路联合调试。

## 4. 各方案依赖关系矩阵（Dependency Matrix）

| 优化子方案 | 前置必要依赖 | 推荐并行执行阶段 | 交付物对后续的输入支撑 |
| :--- | :--- | :---: | :--- |
| **方案 01: 边端解耦** | 无 | 第 1 周 ~ 第 2 周 | 为 Web 前端与 MES 提供统一的高性能元数据订阅接口 |
| **方案 02: 工业视觉** | 现场工位尺寸图纸 | 第 1 周 ~ 第 2 周 | 输出无拖影、光照恒定的高质量视频流底座 |
| **方案 03: 模型量化** | 方案 01 的引擎框架 | 第 1 周 ~ 第 2 周 | 输出可在边缘盒稳定 $\le 3\text{ms}$ 运行的 TensorRT `.engine` |
| **方案 04: PLC 联锁** | 现场机台 PLC 点位表 | 第 2 周 ~ 第 3 周 | 实现从软件告警到机台执行机构物理切断的硬闭环 |
| **方案 05: 双目多视角**| 方案 02（双相机就位） | 第 2 周 ~ 第 4 周 | 将单目二维坐标升维至三维绝对物理空间坐标（X/Y/Z mm） |
| **方案 06: 容灾脱敏** | 方案 01（边缘本地存储） | 第 3 周 ~ 第 4 周 | 确保系统断网不停机并满足企业合规审计 |
