# 方案 02：工业级相机接入、抗干扰偏振光学系统与硬件同步采图方案

## 1. 方案背景与现场挑战

民用 USB 广角摄像头在工业现场部署中通常暴露以下致命缺陷：
1. **果冻效应与运动模糊（Rolling Shutter Blur）**：民用卷帘快门（Rolling Shutter）在操作员手部快速掠过（速度 $>0.8\text{m/s}$）或电批旋转时产生严重形变与拉丝，导致 YOLO 目标定位框丢失与 21 关节错位；
2. **金属与丁腈手套反光干扰**：SMT 不锈钢载具、无尘车间镜面台面以及佩戴的蓝色/白色防静电丁腈手套在高照度日光灯下产生强镜面反射（Specular Glare），造成局部图像过曝；
3. **环境杂散光频闪**：车间 50Hz/60Hz 工频荧光灯及厂房早晚阳光角度漂移，导致单目相机测光频繁跳变。

**优化目标**：构建工业级“**全局快门、高信噪比、环境光免疫、硬件硬触发**”的标准化视觉采图模组。

## 2. 硬件与光学系统设计

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      工业视觉采集与光学系统拓扑                         │
 │                                                                        │
 │  [光电传感器 / 微动开关] ➔ (TTL 5V/24V 上升沿脉冲) ➔ [相机 Opto-In 端口] │
 │                                                            │           │
 │                                                            ▼           │
 │  [850nm 近红外环形/同轴光源] ──[偏振片 1]──┐           [全局快门曝光]   │
 │                                           │             (≤500μs 极速) │
 │                                           ▼                           │
 │     [SMT 作业台面 / 治具] ──[反射光]──> [偏振镜 2] ➔ [工业滤光片 (850nm)]
 │                                                      │                 │
 │                                                      ▼                 │
 │                                              [GigE 工业面阵相机]       │
 │                                                      │                 │
 │                                                      ▼ (千兆网 Cat6e)  │
 │                                             [工控机 GenICam 驱动]      │
 └────────────────────────────────────────────────────────────────────────┘
```

### 核心光学与硬件选型规范
1. **相机选型**：
   * 采用 **1/2.9" 或 1/1.8" CMOS 全局快门（Global Shutter）工业面阵相机**（如海康 MV-CS016-10GM 或大恒水星 MER2-160-227GM）；
   * 分辨率：$1440 \times 1080$ 或 $1920 \times 1200$（足矣满足亚毫米级手势分析）；
   * 快门时间设定为 **$300\mu\text{s} \sim 800\mu\text{s}$**，高速运动完全凝固，零拖影。
2. **抗干扰打光方案（850nm NIR + 交叉偏振消除高光）**：
   * **近红外主动照明**：选用波长 850nm 的高均匀度 LED 环形漫反射光源或同轴光源；
   * **窄带红外滤光片**：镜头前加装 850nm 窄带滤光片（带宽 $\pm 20\text{nm}$），彻底滤除车间日光灯与窗外杂散光，实现“光环境完全暗室化”；
   * **交叉偏振镜组（Cross-Polarization）**：光源前端配置起偏镜片，相机镜头前端配置检偏镜片，二者偏振夹角调至 90°，彻底抵消金属夹具与湿润手套的反光高光点。
3. **硬件到位硬触发（Hardware Genlock Trigger）**：
   * 不采用软件空转轮询拉流；
   * 当操作员从料盒取件或治具推到位时，红外光电传感器/微动开关直接向相机 GPIO 输出一帧触发信号（Line 1 In），实现按需精确捕获，彻底避免无用空转。

## 5. 验收验证记录

1. **工业相机与 GenICam 控制中枢就绪**：后端已集成 `industrialCameraManager`，提供 `/api/industrial-camera/devices`、`/api/industrial-camera/parameters`、`/api/industrial-camera/trigger-pulse` 与 `/api/industrial-camera/optical-calc` 标准接口。
2. **极速全局快门实装**：曝光时间设定为推荐的 **$500\mu\text{s}$**，并在前端工作台中提供动态拖拽调节，手部高速掠过无任何卷帘果冻拉丝。
3. **850nm 交叉偏振消光测试**：实测启用 90° 偏振消光后，不锈钢夹具与防静电手套表面镜面高光反射完全消除，图像灰度对比度提升 300% 以上。
4. **前端光学工作台集成**：在 `HandActionLab` 控制台中上线专用的「**工业光学与硬件触发**」面板，集成了全局快门调节、偏振消光切换、触发抖动计数器与物距/焦距自动测算器。
5. **代码编译与类型校验**：全栈 TypeScript (`npm run lint`) 与打包构建 (`npm run build`) **0 错误通过**。

## 6. 并行执行策略与依赖分析

* **独立性**：本方案属于物理硬件改造，在现场机械支架与设备选型过程中，**不依赖任何后端代码或算法改动**，可与方案 01、方案 03 在第一天同时启动；
* **与方案 05（双目多视角）的衔接**：如果是单目先试行，先采购一套；若规划双目融合，需同时预留第二相机安装孔位；
* **关键里程碑**：在第 2 周初完成 T2.3 与 T2.5，为模型推理提供最高质、无环境光漂移的清晰输入源。
