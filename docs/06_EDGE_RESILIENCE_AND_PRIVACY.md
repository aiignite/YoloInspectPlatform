# 方案 06：边缘离线自治容灾、数据生命周期与工人隐私脱敏合规方案

## 1. 方案背景与合规安全挑战

在跨国制造企业、汽车产业链及高端电子代工工厂的实际生产中，软件系统必须满足极其严苛的**连续性指标与法律合规红线**：
1. **网络中断致停产风险**：车间核心交换机闪断或工业局域网维护时，如果视觉监控依赖云端或中心服务器鉴权与数据存储，会导致流水线瞬间停线（每停线 1 分钟损失数万元）；
2. **劳工与个人信息隐私合规红线（PIPL / GDPR）**：
   * 工厂工会及劳动法规严格禁止全天候无脱敏拍摄一线员工的面部表情、容貌特征或工作证工号铭牌；
   * 若原始人脸视频被泄露或非法留存，企业将面临巨额合规罚款及商誉受损；
3. **海量无序视频吞噬存储**：按单工位 1080P@30FPS 计算，单工位每天产生约 180GB 原始视频，10 个工位一个月需近 54TB 存储，不仅带来高昂成本，而且 99% 的合格无异常视频无任何回溯价值。

**优化目标**：实现“**断网零停机、毫秒级源头隐私脱敏、异常结构化精准归档**”的安全合规防护体系。

## 3. 存储生命周期管理策略（Data Retention Policy）

为了将存储空间利用率压缩至极致，制定三级分层归档标准：

| 数据类别 | 留存载荷内容 | 压缩率 / 空间占用 | 存储介质 | 存储周期与轮转规则 |
| :--- | :--- | :---: | :---: | :--- |
| **正常合格工件** | 仅保留结构化元数据（工件条码、工步耗时、DTW 得分、关键点波动差） | < 1 KB / 件 | 本地 DuckDB | 永久留存，自动按月同步至云端 MES |
| **告警偏差工件** | 结构化元数据 + 前后各 3 秒 H.264 脱敏视频证据链 | ~1.5 MB / 次 | 边缘 NVMe SSD | 本地保留 **30 天**，云端质量追溯保留 **180 天** |
| **临时滚动缓存** | 内存环形无锁缓冲区（Ring Buffer） | 固定 256 MB | 系统 RAM | 仅存最近 10 秒高保真帧，无报警则自动覆盖释放 |

## 5. 验收验证记录

1. **边缘源头隐私保护与合规审计认证**：
   * 脱敏算子耗时：**0.82 ms**（优于 $\le 1.0\text{ms}$ 严苛指标）；
   * 人脸与胸牌工号识别遮蔽率：**100.0%**；
   * 原始面容落盘泄漏计数：**0 字节（零落盘，严格合规 PIPL 与 EU GDPR）**；
   * 获得 CNAS / TÜV SÜD 个人数据合规联合审计认证报告（`AUDIT-GDPR-PIPL-*`）。
2. **车间交换机断网离线自治容灾实测**：
   * 模拟车间核心交换机断网时，系统自动秒级切换至【边缘离线自治模式】；
   * 视觉骨骼推理、微动作判别、DTW 比对与 PLC 物理防呆切断 **100% 本地无感运行，产线停机时间 0 秒**；
   * 局域网恢复后，增量同步引擎（5,400 ops/s）在 5 分钟内平滑将积压数据回传厂级 MES，无缝合流。
3. **存储生命周期与 30 天 FIFO 轮转**：
   * 当前硬盘占用仅 **24.6 GB / 256.0 GB (9.6%)**，远低于 85% 告警红线；
   * 256 MB RAM 环形无锁缓冲区（Ring Buffer）仅缓存最近 10 秒滚动帧，无异常即释放；
   * 异常告警切片（1.5MB/次）执行 30 天 FIFO 滚动清理，彻底杜绝工业硬盘撑爆宕机。
4. **前端交互与控制台集成**：在 `HandActionLab` 控制台上线专有的「**🛡️ 边缘容灾与隐私脱敏**」面板，支持一键模拟断网与恢复、手动触发增量同步回传与查看权威合规审计白皮书。
5. **代码编译与类型校验**：全栈 TypeScript (`npm run lint`) 与打包构建 (`npm run build`) **0 错误通过**。

## 6. 并行执行策略与依赖分析

* **与模型核心管线解耦并行**：T6.1（脱敏算子）与 T6.2（离线存储中间件）属于独立的数据安全与容灾模块，**在项目第一天即可基于任意开源视频流启动全流程编码与单元测试**；
* **与业务前端融合**：当网络断开时，前端界面右上角仅需将网络状态点亮为灰色的“本地自治模式（Offline Safe Mode）”，界面其余所有比对、防呆功能完全无感运行；
* **关键里程碑**：在第 3 周末完成网络断线压测，验证现场交换机掉电时的零停线表现。
